# Open Scribe Agent Contract

This file routes work to repository truth. `CLAUDE.md` is its byte-identical mirror; `./script/check.sh --scaffold` enforces that invariant.

## Current stage

Read current capability and milestone evidence in `ANCHOR.md`, `ACTOR.md`, and
its named runtime receipts. Reacquire the exact checkout and receipt before
making a capability claim. Short unsigned capture/recovery proof cannot prove
source-loss continuation, permission revocation, application-scoped selection,
long-session synchronization, transcription, signing, or release.

## Task routing

Read `ANCHOR.md` for invariants. For product or architectural decisions, read
the relevant clauses of `docs/product/FOUNDING_PRD.md` and the mission projection
in `NORTH_STAR.md`. Use `LAYERS.md` to resolve disputed ownership. Then select
`ARCHITECTURE.md` for structure, `ACTOR.md` for verified actions, `NUANCE.md` for
reproduced traps, or `SOUL.md` for non-authoritative posture. Read the clauses
that govern the task; routine work does not require every sidecar.

## Authority and change control

- The founding PRD wins over its projections. An approved ADR may supersede only the clauses it names; record approver, evidence, and migration effect.
- Separate observed repository fact, founding decision, proposed choice, and unknown.
- Describe intended-but-unbuilt components as **intended**, never current.
- Do not create parallel sources for legal text, capability definitions, model manifests, export formats, schema versions, or terminology.
- Preserve unrelated and unknown-owner work. Inspect branch, worktree, dirty state, and rollback before mutation.

## Product and architecture guards

- Implement one milestone at a time. Bootstrap may not silently expand into capture or ML.
- Reliability and recoverability precede intelligence.
- Swift owns Apple-only UI/platform adapters. Rust owns durable state, evidence, recovery, provider policy, and exports. UniFFI stays coarse; frame-rate media and pointer samples do not cross ordinary callbacks.
- Shared Rust crates must compile for `wasm32-unknown-unknown` and may not depend on native crates.
- Remote-provider selection is not content-scope authorization.
- No claim of local-only, recovery, grounding, deployment, signing, or release without the exact corresponding proof plane.
- Never introduce Python, FastAPI, React, Tauri, Electron, a localhost application server, implicit cloud processing, or continuous default screenshot retention.

## Work and proof

- Use `rg`/`rg --files` for discovery and `apply_patch` for authored edits.
- Add commands to `ACTOR.md` only after they execute successfully in this checkout.
- Run the narrowest relevant check, then inspect `git diff --check` and `git status --short --branch`.
- `./script/check.sh --scaffold` validates only the founding scaffold. Default product gates fail closed until implemented.
- Do not commit, push, create a PR, deploy, mutate Cloudflare, archive Speaker Scribe, or change external systems without explicit authority.

## Stop conditions

Stop on a material PRD conflict, an ownership collision, unscoped remote data flow, native leakage into shared crates, frame-rate UniFFI serialization, unrecoverable capture design, incompatible licensing, dishonest permission state, or a request to infer a higher proof plane from a lower one.

## Reground operators

- `look north` — reopen `NORTH_STAR.md`, then `ANCHOR.md`.
- `classify layers` — name the owner, constraint, realization, and proof.
- `check agency` — verify permission, preconditions, proof, and rollback.
- `reconcile` — expose divergence; do not narrate it into false coherence.
