# Open Scribe 0.1.0 — Candidate Notes

Status: **not released; preparation hold**

Open Scribe 0.1.0 is the planned first public release. No version has been
allocated, signed, notarized, packaged, published, or deployed. These notes
describe the current candidate truth and must be rebound before release.

## Qualified development capabilities

- Rust-owned durable conversation preparation, source identity, media-open,
  first-sample, sealing, interruption, and atomic recovery state.
- Short, explicit microphone plus all-authorized system-audio development
  capture and forced-termination recovery receipts from earlier exact runtime
  candidates. They are not long-session or permission-revocation proof.
- One native conversation library for live, recovered, and imported media.
- Managed CAF import with stable source identity, bounded pathless playback,
  byte validation, and generation-bound cleanup across stop, failure,
  replacement, recovery, and natural completion.
- A native macOS conversation workspace with shared Record/Import authority,
  truthful recovery and playback state, and deterministic source-focused tests.
- Content-free capture-health observations that preserve Rust lifecycle
  authority.

## Not yet available

- Live or final transcription, diarization, speaker correction, transcript
  search, transcript-synchronized playback, and evidence exports.
- Application-scoped audio selection, source-loss continuation,
  permission-revocation recovery, disk-pressure qualification, and long-session
  synchronization.
- Screen-context observation, evidence-linked meeting intelligence, remote
  providers, and production deletion/export workflows.
- A signed or notarized application, automatic updates, public download,
  deployed capability-true website, or supported release.
