# Capability Claim Authority

`manifest.v1.json` is the checked claim vocabulary defined by ADR 0015. It is
truthful at the source-claim plane: the native shell and bounded earlier
microphone plus all-authorized system-audio capture and atomic two-track
forced-termination recovery are labeled development `Fixture` capabilities.
Those earlier runtime receipts do not prove the present candidate. Source-loss continuation,
transcription, conversation management, context, and intelligence remain
`Unavailable`.

This manifest is not runtime proof. `open-scribe-core` owns a checked compile-time
registry at `crates/open-scribe-core/runtime-capabilities.v1.json`; the native
core embeds those exact bytes, and its emitter binary writes the embedded value.
Read-only preparation validates source linkage and normalized equality with this
checked claim manifest. Exact compiled-artifact embedding remains a separate
release proof, and this checked claim file alone is not binary evidence.
