# Open Scribe Privacy Notice

> **Draft — not adopted, not legal advice, and not a description of an implemented product.**

Open Scribe is intended to be a local-first macOS conversation recorder. The founding design requires explicit capture, visible scope, local storage, no required account, no required telemetry, local OCR reduction, discarded raw screen pixels by default, and per-category authorization before any remote provider receives content.

No application or service currently exists in this repository, so this draft makes no claim about deployed behavior.

Before release, this notice must accurately disclose:

- captured audio, optional video, transcript, participant/topic input, markers, context events, retained snapshots, imports, diagnostics, and derived memory;
- purpose, local storage paths, retention, deletion, Trash and backup behavior;
- each optional network flow, endpoint category, provider, content scope, retention warning, and cost control;
- model downloads, update checks, website requests, and Apple platform trust behavior;
- optional Calendar, Contacts, Accessibility, notification, file, microphone, and screen/system-audio permissions;
- Time Machine and portable-export treatment;
- security safeguards and their platform limitations;
- user choices, revocation behavior, and contact/disclosure channels.

The native app and website must render this single canonical text or a deterministic projection. Separately edited copies are prohibited.
